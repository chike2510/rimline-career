# Real NBA Data Sources

RIMLINE will use the NBA as its real-world league reference. The official NBA Teams & Rosters page lists the 30 franchises and provides profile, statistics, and schedule links for each team: https://www.nba.com/teams.

The official NBA roster announcement states that the 2025-26 regular season rosters were set for all 30 teams and provides the season context for opening-night roster data: https://www.nba.com/news/nba-rosters-set-for-2025-26-regular-season.

Implementation boundary: use real franchise and player names for an unofficial fan-made simulation, but do not ship NBA team logos, player headshots, or other protected artwork unless the user supplies licensed assets or grants an appropriate license. The UI will display a clear non-affiliation notice and use text-based team marks/initials for offline operation.

Source snapshot date: 2026-08-24.
