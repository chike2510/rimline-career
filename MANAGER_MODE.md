# RIMLINE Manager Mode

Manager Mode reframes the fantasy from personal box-score performance to franchise stewardship. The player becomes the Boston Comets front office, balancing culture, game plan, scouting, and roster identity.

## Core manager loop

1. Review team record, chemistry, morale, defense, and scouting readiness.
2. Select a game-plan focus: Balanced, Run & Gun, or Lockdown.
3. Apply a staff action: run a team session, install a defensive package, or scout the next opponent.
4. Read the next decision prompt and return to the next game.

## Manager metrics

| Metric | Meaning | Current MVP action |
|---|---|---|
| Chemistry | Shared execution and role clarity | Team session |
| Morale | Confidence and emotional stability | Future event hooks |
| Defense | Team defensive floor | Defensive package |
| Scouting | Opponent information advantage | Scout next opponent |

Manager Mode shares the same local save and app shell as Player Mode. It is intentionally additive: the player can switch modes without creating a second career or requiring network access.
